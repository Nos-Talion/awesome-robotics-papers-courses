# Contributing

Thank you for helping keep this collection accurate and useful.

## Before proposing an entry

Please check that the resource:

1. is directly relevant to robotics;
2. has a stable first-party link (DOI, arXiv, publisher, author project, university course, or official documentation);
3. is not already listed;
4. adds clear educational or technical value;
5. can be described factually in one or two sentences.

Do not upload or link to pirated papers, books, videos, datasets, or course files. Do not use URL shorteners or unofficial mirrors when a first-party page exists.

## Paper entry format

```markdown
- **[Paper title](official-paper-url)** · [Project](optional-project-url) — Authors, year. **Preprint.** One factual sentence explaining the contribution.
```

- Preserve the official title and publication year.
- Add **Preprint.** when the cited version is not formally published.
- Prefer the DOI for published work and arXiv for preprints.
- Link code only when it is maintained by the authors or their organization.
- Do not use citation count as the only justification.

## Course entry format

```markdown
- **[Course title](official-course-url)** — Institution. Topics and openly available materials.
```

Mention whether lectures, notes, assignments, or code are publicly available. Avoid linking to student-uploaded copies of restricted materials.

## Pull requests

- Keep each pull request focused on one category or a small coherent set of entries.
- Explain why each addition belongs in the collection.
- Check spelling, Markdown rendering, and all links.
- Do not reorder unrelated sections or perform broad formatting changes in the same pull request.

Maintainers may decline technically valid resources to keep the list selective and balanced.
