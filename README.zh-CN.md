# 机器人论文与课程精选

[![许可证：MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

这是一个开源、持续维护的机器人学习路线，收录经典论文、前沿研究、大学课程、教材、数据集和软件工具。

[English](README.md) · **简体中文**

> 本仓库只链接论文官方页面、出版社记录、作者项目页和课程官网，不转载受版权保护的论文 PDF 或课程文件。

## 从哪里开始

| 学习目标 | 建议顺序 |
|---|---|
| 机器人基础 | Modern Robotics → 运动学与动力学 → 反馈/阻抗控制 → 运动规划 |
| 机器人学习 | 监督学习基础 → 模仿学习 → 强化学习 → 扩散策略 |
| 机器人操作 | 几何与控制 → 抓取 → 视觉运动策略 → 大规模操作数据集 |
| 移动机器人与 SLAM | 状态估计 → 定位与建图 → 视觉/激光 SLAM → 语义感知 |
| 视觉-语言-动作模型 | 模仿学习 → Transformer/扩散模型 → RT 系列 → 开放通用策略 |
| 触觉操作 | 传感器原理 → 触觉仿真 → 表征学习 → 视触觉策略 |

## 收录原则

条目应尽量满足以下条件：

- 在技术史、学习价值或开源实现方面具有代表性；
- 使用稳定的一手来源链接；
- 按知识依赖和学习顺序组织，而不是只追逐最新论文；
- 用简短、客观的文字说明其价值；
- 明确区分正式发表论文和预印本。

本项目追求“精选且可维护”，而不是穷尽所有论文。收录不代表对论文结论、产品或机构的背书。
