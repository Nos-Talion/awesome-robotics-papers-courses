## Start here

Choose a route based on what you want to build.

| Goal | Suggested order |
|---|---|
| Robotics fundamentals | Modern Robotics → kinematics and dynamics → feedback/impedance control → motion planning |
| Robot learning | supervised learning basics → imitation learning → reinforcement learning → diffusion policies |
| Robot manipulation | geometry/control → grasping → visuomotor policies → large-scale manipulation datasets |
| Mobile robotics and SLAM | state estimation → mapping/localization → visual/LiDAR SLAM → semantic perception |
| Vision-language-action models | imitation learning → Transformers/diffusion → RT series → open generalist policies |
| Tactile manipulation | sensor principles → tactile simulation → representation learning → visuotactile policies |

## How entries are selected

An entry should satisfy most of the following:

- technically important, educationally useful, or a strong reference implementation;
- linked through a stable first-party source;
- placed in a clear learning sequence rather than added only because it is recent;
- accompanied by a short, factual explanation of why it matters;
- openly accessible metadata, with access conditions clearly stated when material is not fully open.

Preprints are welcome when they are influential or introduce a useful open artifact, but they are labeled **Preprint**. Inclusion is not an endorsement, and the list is intentionally selective rather than exhaustive.
